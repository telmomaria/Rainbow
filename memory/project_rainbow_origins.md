Rainbow nasceu por #NP a 2026-11-11 a partir do `-TEMPLATE_v7` (motor `AGENTS_v7.md`). **Sem projeto-pai**: não herda
código nem padrões de outro projeto ANTIGRAVITY (a stack FastAPI+Next.js+Supabase do #NP global NÃO se aplica).
É o primeiro jogo da família, feito para crianças de 7–8 anos (contexto familiar do Telmo).

Decisões do dia 1: PT-PT · uma só janela (sem LINEAGE) · sem MCP · porta 1234 · repo https://github.com/telmomaria/Rainbow.git ·
personagens originais inspiradas em arquétipos (sem IP Disney / KPop Demon Hunters) · interatividade descoberta pelo
movimento, sem UI indicadora.

Linhagem: não existe `goat_registry.md` no setup; o BOOK-map ("A Lacuna da Percepção") é estático/fechado — o nascimento do
Rainbow fica registado aqui e em `docs/diary/` até haver um 2.º volume. Ver [[project-rainbow-stack]].

Decisões 2026-11-15/17: mundo gerado (sem OSM); final Nuuk → EUA → Lua (altar + joias); arranque/morada cancelada;
hotel EUA = **Hotel das Fontes** (inspirado Bellagio, sem marca); Parque Arco-Íris = castelo de contos (não Disney).

Decisões 2026-11-19: o fim é uma **máquina do tempo** enterrada na Lua que leva a personagem para o **"Rainbow 2"** (há
intenção de uma sequela); joias para acabar = as trazidas + 10; área a dobrar abandonada; ex-líbris das cidades vazias
ficam para depois.
